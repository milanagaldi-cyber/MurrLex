# Project Context

## Product

MurrLex is a personal language-learning app. The core unit is a card inside a lesson. Cards can represent mistakes, vocabulary, translation pairs, or practice prompts.

## Current Goal

This checkpoint is a stable Android_Main handoff after the Translate/Split online/offline translator work. The goal is to preserve a buildable state and make the next thread easy to start.
