# Project Context

## Product

MurrLex is a personal language-learning app. The core unit is a card inside a lesson. Cards can represent mistakes, vocabulary, translation pairs, or practice prompts.

## Current Goal

This checkpoint is a stable Android handoff before a clean Codex v0.02 thread. The goal is not to add features now, but to preserve a buildable state and make the next thread easy to start.
