# Lexamora Studio: User Workflows

## Create production workspace

1. Sign in with the existing MurrLex account.
2. Create a workspace and invite collaborators.
3. Assign Viewer, Translator, Editor or Admin roles.
4. Create a Series or Standalone Video project.
5. Add concept, languages, rights and publication metadata.

## Build an episode

1. Add characters and private visual references.
2. Create an episode and ordered scenes.
3. Edit hook, location, action, performance and dialogue in the scene editor.
4. Create model-specific image/video prompts from structured blocks.
5. Reorder scenes; collaborators see the canonical order.

## Improve a prompt

1. Select blocks or a non-dialogue/full-prompt mode.
2. Choose an AI model profile.
3. Review the suggestion beside current text.
4. Accept or reject it. Acceptance creates a revision and audit event.

Dialogue references are preserved and cannot be silently rewritten.

## Assets and generations

Upload an original through a scene or character, inspect its thumbnail and download
it through the authenticated action. Additional generations keep their reason,
source, prompt and multiple outputs; one output may be selected as final.

## Subtitles and translation

Create a working track, bulk-paste and reorder lines, then approve a final track.
Translate source units side by side. Approved source changes mark translations
STALE and linked prompts for review.

## Version recovery

Open Activity, compare two revisions and restore a historical snapshot. Restore is
recorded as a new revision and preserves all earlier history.

## Export

Choose a project or episode and sections, generate a PDF, monitor the job and
download the private result. Generation and download appear in audit history.

## Import the current Master Document

1. Upload DOCX as a private source asset.
2. Review detected metadata, episodes, scenes, dialogue, prompt tables, images,
   additional generations and subtitles.
3. Resolve ambiguous headings and unmatched tables.
4. Accept the draft to create canonical records and an audit event.
